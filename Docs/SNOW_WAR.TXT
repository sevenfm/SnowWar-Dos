                1. Постановка задачи


    Разработать игровую объектно-ориентированную программу.
    Игра "Снежная война" представляет собой разновидность пошаговой
стратегической игры. Основная идея игры - сражение 2-х армий
снеговиков на карте.   Одна  из  армий  управляется
компьютером, а другая - пользователем.
Игра заканчивается, если уничтожена вся армия
противника   или   захвачен   его  флаг. Снеговики имеют следующие
характеристики:
     1. Жизненная энергия. Снеговик тает, когда его жизненная энергия
достигает нуля. Энергия уменьшается при попадании.
     2. Время,  отводимое  на один ход. Любое перемещение или выстрел
требуют расхода времени.
     3. Мощность и дальность оружия. Определяет повреждения, наносимые
противнику при попадании, и дальность стрельбы.
     4. Время, затрачиваемое на один выстрел.
    Снеговики    бывают    четырех    типов,    различающихся   своими
характеристиками:
     1. Снеговик обыкновенный.
     2. Ледовик.
     3. Саночник.
     4. Огневик.
    Карта  сражения  генерируется  случайным  образом и содержит такие
структурные элементы, различающиеся временем проходимости, как то:
     1. Снег.
     2. Рыхлый снег.
     3. Лед.
     4. Тропинка.
     5. Дерево.
    На карте случайным образом разбросаны т.н. бонусы. Встав на клетку
с бонусом, снеговик изменяет свой тип. В начале игры все солдаты имеют
один и тот же тип - снеговик обыкновенный.
    В   таблице   рекордов  хранятся  имена  и  очки  десяти  игроков,
добившихся наилучших результатов в игре.

                 2. Описание программы.

    Программа  написана  на  Borland  C++  версии 3.0 с использованием
графической библиотеки The Graphics Engine.
    Описание интерфейсной части классов:

1. Класс координат.

class Coord{
  public:
    Coord(int aX,int aY);       // конструктор
    Coord(void);                // инициализирует нулями
    Coord(Coord &aCoord);       // создает копию
    int GetX(void);             // возвращает координату x
    int GetY(void);             // возвращает координату y
    void SetX(int aX);          // устанавливает координату x
    void SetY(int aY);          // устанавливает координату y
    int operator ==(Coord c);   // \
    int operator !=(Coord c);   // -  перегрузка стандартных
    Coord operator =(Coord c);  // -  операций
    Coord operator +(Coord c);  // /
    int Distance(Coord b);      // расстояние до b
    int Dist2(Coord b);         // квадрат расстояния до b
    int IsDiag(Coord b);        // TRUE - если b диагональна к this
    Coord GetMap();             // графические коорд. - в позицию на карте
    Coord GetScreen();          // наоборот
};

    ~Army();                             // уничтожает снеговиков

class ComputerArmy:public Army{   // армия компьютера, производный от Army
  friend class HumanArmy;         // необходимо знать расположение солдат
                                  // противника
  public:
    ComputerArmy();         // создает армию
    int Move();             // один ход,
                            // возвращает: 0 - игра продолжается, 1 - победа
    void SetEnemy(HumanArmy *Enemy);   // указатель на противника
};

class HumanArmy:public Army{      // армия человека, производный от Army
  friend class ComputerArmy;      // необходимо знать расположение солдат
                                  // противника
  public:
    HumanArmy(DeskTop *aDeskTop);         // создает армию
                                          // aDeskTop - экран
    void SetEnemy(ComputerArmy *Enemy);   // указатель на противника
    int Move();    // 0 - игра продолжается, 1 - победа, 2 - прервано
};

          3. Внешние файлы.

1)
  .raw - графический формат, поддерживаемый TGE
    Первые четыре байта - ширина и высота картинки.
Далее - неупакованная картинка

2)
  .pal - VGA палитра.
    768 байт в формате RGB 8-бит.

3)
  640x480.drv - графический драйвер TGE.
    Загружается при инициализации библиотеки.

4)
  hiscore.tbl - таблица рекордов.
    Состоит из десяти записей.
Каждая запись - имя игрока из 16 символов и 2 байта очков.

5)
  bigtext.fnt - шрифт.
    Используется библиотекой TGE для вывода текста на экран.

        5. Инструкция пользователю.

    Для старта программы необходимо запустить файл snow.exe.
    После запуска программы пользователь попадает в главное меню, в котором
может выбрать одну из следующих опций:
1) Игра.  Запускает игру.
2) Таблица рекордов. Показывает таблицу рекордов.
3) Авторы. Информация об авторах программы.
4) Выход :-(

    Цель игры - уничтожить армию противника либо захватить ее флаг.

    В игровом окне пользователь может:
1) нажать на кнопку выхода
2) нажать на кнопку завершения хода
3) выбрать одного из своих снеговиков
    При   выборе  снеговика  в  нижней  части  экрана  отображается
его  имя  и характеристики.
    С выбранным снеговиком можно производить следующие действия:
1) Указать курсором клетку, куда нужно идти.
2) Указать противника, в которого нужно стрелять.

    Если  снеговик  становится  на  клетку с бонусом, он изменяет свой
тип.

    После  окончания  игры,  пользователь  либо возвращается в главное
меню,  либо  попадает  в таблицу рекордов, где ему предлагается ввести
свое имя.
